# Missy : TO-DO List for _Procrastinators_
---
_Work in Progress : No stable version_

## Description:
Missy is a to-do list for procrastinators like us that adds spice and
fun-engagement for tasks by turning it into _gameified_ todos!

*Features:*
- A cute desktop companion named _Missy_ 
- Gameified tasks that rewards you for every completion
- Highly interactable design
